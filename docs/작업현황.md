## 알려진 점

- 웹 한글 입력은 HTML 입력칸을 겹치는 방식이라, 화면의 커서가 실제 위치와 다르게 보일 수 있다. 모바일 브라우저는 이 방식을 쓰지 않고 확인하지 않았다.
- 웹 채팅은 보내기 버튼으로 보내면 겹친 입력칸이 닫혀서, 다시 눌러야 이어서 칠 수 있다. (엔터로 보내면 이어서 칠 수 있게 만들었다)
- 웹 방 코드 복사는 Safari와 모바일을 확인하지 않았다. 막히면 복사 대신 코드가 화면에 보인다.
- 웹에서 `WebGLInput.captureAllKeyboardInput`을 꺼서, 캔버스를 한 번 클릭해야 키 입력이 게임으로 간다.

## 결정한 것

- 선턴 결정은 지금 코드의 무작위 방식을 유지한다.
- 웹 전용 코드는 `#if UNITY_WEBGL && !UNITY_EDITOR`와 `Plugins/WebGL`로 분리해 Windows와 에디터를 바꾸지 않는다.
- 파일 위치 안내는 줄 번호가 아니라 함수와 주석 이름으로 한다.
